Вхід до адмін-панелі

Зміни зберігаються прямо в репозиторій сайту на GitHub. Сайт оновлюється приблизно за 1–2 хвилини після публікації.

Наприклад, redeko2023/candlesB2C

Як отримати токен
  1. На GitHub відкрийте Settings → Developer settings → Personal access tokens → Fine-grained tokens і натисніть Generate new token.
  2. Назва — наприклад, «Адмінка свічок». Термін дії — на ваш розсуд (наприклад, 1 рік).
  3. Repository access → Only select repositories → оберіть репозиторій сайту.
  4. Permissions → Repository permissions → Contents → Read and write. Інші дозволи не потрібні.
  5. Натисніть Generate token, скопіюйте токен і вставте його сюди.

Токен дає право змінювати лише цей репозиторій. Не пересилайте його іншим. Якщо токен потрапив до сторонніх, видаліть його на GitHub і створіть новий.
